# tinytensor_rust — ускорение im2col на Rust

Переписанная на Rust функция `im2col` (разворачивание картинки в матрицу для
свёртки). На чистом NumPy это узкое место свёрток на CPU; на Rust — быстрее,
потому что нет питоновского оверхеда и всё компилируется в машинный код.

## Что это ускоряет

Только **CPU-путь** свёрток. На GPU (CuPy) остаётся прежний код — там уже
быстро через вендорские ядра. То есть Rust помогает, когда обучаешь на
процессоре.

## Сборка (у тебя уже стоит Rust — cargo нашёлся)

1. Поставь maturin (инструмент сборки rust->python) в своё окружение:
   ```
   pip install maturin
   ```

2. Собери и установи модуль. Из папки `tinytensor_rust/`:
   ```
   maturin develop --release
   ```
   `--release` включает оптимизацию (без него будет медленно).
   `develop` ставит модуль прямо в текущее окружение (miniforge).

3. Проверь, что модуль встал:
   ```
   python3 -c "import tinytensor_rust; print('rust ok')"
   ```
   Если напечатало `rust ok` — готово.

## Как оно подключается

В `tinytensor/nn/functional.py` уже добавлена развилка: при импорте библиотека
пытается подключить `tinytensor_rust`. Если модуль собран — im2col на CPU идёт
через Rust. Если нет — работает старый NumPy-код (fallback). То есть библиотека
не сломается, даже если Rust не собран: просто будет медленнее.

Проверить, что ускорение активно:
```
python3 -c "import tinytensor.nn.functional as F; print('rust активен:', F._HAS_RUST)"
```

## Проверка корректности

Rust-версия даёт побитово тот же результат, что NumPy (проверено на разных
размерах, паддингах и stride). Чтобы убедиться самому после сборки:
```
python3 test_correctness.py
```

## Замер ускорения

После сборки прогони бенчмарк из examples — conv на CPU должен ускориться:
```
PYTHONPATH=. python3 examples/benchmark_vs_pytorch.py
```
Сравни с тем, что было до Rust.

## Если что-то пошло не так

- `maturin: command not found` — не установился maturin, повтори `pip install maturin`.
- ошибки компиляции про pyo3/numpy версии — проверь, что версии в Cargo.toml
  подходят твоему Python (для 3.13 нужен свежий pyo3, версия 0.20 подходит).
- модуль собрался, но `_HAS_RUST=False` — модуль встал не в то окружение;
  убедись, что maturin и python из одного miniforge.
